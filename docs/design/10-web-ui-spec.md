# Web UI 规格

本文档细化本地 Web GUI 的布局, 组件, 状态与交互. 接口契约见 [07-local-api-web.md](07-local-api-web.md), 本地安全约束见 [03-auth.md](03-auth.md).

## 1. 目标与约束

- 浏览器只访问 `http://127.0.0.1:<port>/`, 不直连远端服务端.
- 页面不持有服务端 token, 不把 token 写入 `localStorage`, URL 或日志.
- 所有数据通过同源 `/api/*` 获取.
- 首屏在本地环境 1.5 秒内可用, 图表按需加载.
- 中文界面, 时间与数字按 `ui.timezone` 与浏览器区域设置展示.
- 桌面优先, 同时支持手机浏览器.

## 2. 设计原则

- 状态优先: 用户打开页面第一眼要知道当前是否正常, 电量是多少, 数据是否新鲜.
- 少层级: 四个主页面足够, 不引入复杂导航.
- 明确危险操作: 归档与删除必须二次确认并说明后果.
- 失败可恢复: 每个错误状态都有下一步动作, 不只显示错误码.
- 不隐藏数据来源: 显示最近采样时间, 数据是否来自缓存, 下一次采集时间.
- 颜色不是唯一信息载体: 状态同时用文字与图标表达.

## 4. 设计令牌

### 4.1 颜色

| 语义 | 浅色 | 深色 | 用途 |
|------|------|------|------|
| 背景 | `#f7f8fa` | `#0f1115` | 页面底色 |
| 表面 | `#ffffff` | `#171a21` | 卡片 |
| 边框 | `#e5e7eb` | `#2a2f3a` | 分隔线 |
| 主文字 | `#111827` | `#e5e7eb` | 正文 |
| 次文字 | `#6b7280` | `#9ca3af` | 说明 |
| 强调 | `#2563eb` | `#60a5fa` | 链接, 主按钮 |
| 正常 | `#16a34a` | `#4ade80` | 健康状态 |
| 警告 | `#d97706` | `#fbbf24` | 低电量, 上游异常 |
| 危险 | `#dc2626` | `#f87171` | 断网, 服务端不可达 |
| 中性 | `#6b7280` | `#9ca3af` | 未配置, 未知 |

- 对比度至少 4.5:1.
- 状态色不单独使用, 必须配文字或图标.

### 4.2 字体

- 系统字体栈: `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`.
- 数字使用 `font-variant-numeric: tabular-nums`, 避免刷新时跳动.
- 正文 14px, 行高 1.6.
- 页面标题 24px, 卡片标题 16px.
- 当前电量大字 40px, 单位 16px.

### 4.3 间距与圆角

- 间距刻度: 4, 8, 12, 16, 24, 32.
- 卡片内边距 20px, 卡片间距 16px.
- 圆角 8px, 按钮 6px, 徽标 999px.
- 阴影仅用于浮层与下拉, 保持内容层级清晰.

### 4.4 主题

- 默认跟随系统 `prefers-color-scheme`.
- 顶部栏提供浅色 / 深色 / 跟随系统三态切换.
- 选择保存在 `localStorage` 的 `dormwatt.theme`, 不属于敏感数据.
- 图表颜色从 CSS 变量读取, 切主题时重绘.

- 所有错误提示使用文本渲染, 不使用 `v-html`.

## 6. 页面规格

### 6.1 仪表盘 `/`

数据来源:

- `GET /api/status`, 每 5 秒.
- `GET /api/records?from=now-7d`, 首次加载与手动刷新.
- `GET /api/degree?fresh=true`, 仅点击刷新按钮时.

布局:

```
+----------------------+ +----------------------+
| 当前电量 33.43 度      | | 今日用量 1.24 度       |
| 采样于 14:35:32       | | 预计可用 27 天         |
+----------------------+ +----------------------+
| 状态横幅: 正常 / 未登录 / 未选房 / 服务端不可达 ... |
+---------------------------------------------------+
| 7 天剩余电量曲线                                    |
+---------------------------------------------------+
| 最近记录表 (5 条)               [查看全部]          |
+---------------------------------------------------+
```

状态:

- `ok`: 显示绿色徽标与正常文案.
- `no_room`: 卡片显示 "尚未选择房间", 主按钮 "选择房间".
- `not_logged_in`: 横幅提示登录失效, 按钮 "如何登录".
- `server_down` / `no_net`: 红色横幅, 显示自动重试时间.
- `tls_error`: 红色横幅, 提示证书或代理配置.
- `upstream_error`: 黄色横幅, 显示服务端返回的 detail.
- 无记录: 图区显示 "等待第一次采样", 不显示空坐标轴.
- 数据过期: 如果 `last_sample_at` 超过采集周期两倍, 卡片显示 "数据可能过期".

交互:

- 刷新按钮触发 `/api/degree?fresh=true` 与 records 重载.
- 选择房间打开房间选择弹窗.
- 登录帮助跳转 `/settings#login`.
- 点击最近记录行跳转 `/records` 并带上时间范围.

### 6.2 记录 `/records`

URL 参数:

```
/records?from=2026-01-01T00:00:00%2B08:00&to=2026-01-31T23:59:59%2B08:00&view=chart
```

- `from`, `to`: RFC3339, 可省略.
- `view`: `chart` 或 `table`.
- `room`: 房间 id, 可省略.

布局:

```
+---------------------------------------------------+
| [24h] [7d] [30d] [全部] [自定义]   [房间 v] [导出]  |
+---------------------------------------------------+
| 曲线图                                              |
|  - 剩余电量折线                                     |
|  - 每日用量柱状                                     |
|  - 缩放条                                           |
+---------------------------------------------------+
| 框选统计卡: 起止 / 用量 / 日均 / 预计可用 [归档]     |
+---------------------------------------------------+
| 表格 / 图表切换                                     |
+---------------------------------------------------+
```

交互:

- 时间预设切换后更新 URL 与数据.
- 自定义范围使用日期时间选择器, 必须带时区.
- 图表支持滚轮缩放, 拖动平移, 双击复位.
- 框选:
  - 使用 ECharts `brush` 选择 X 轴区间.
  - 选择后显示 `StatsCard`.
  - `StatsCard` 的 "归档此范围" 打开归档对话框并预填时间.
- 表格默认显示最近 500 条, 提供 "加载更多" 与 "导出全部 CSV".
- 导出调用 `/api/records?format=csv`, 使用同源链接下载.
- 空数据: "该时间范围没有记录", 提供 "查看全部".
- 超过 200000 条: 提示收窄范围, 并保留 CSV 导出.

统计规则:

- 用量差值: `delta[i] = max(0, degree[i-1] - degree[i])`.
- 电量回升视为充值, 不计入用量, 并单独标记.
- 日均用量: 区间用量除以覆盖天数, 不足一天按实际小时折算.
- 预计可用天数: 当前电量除以日均用量, 无用量时显示 `-`.

### 6.3 归档 `/archives`

数据来源:

- `GET /api/archives?room_id=<active>`.
- 切换房间时重新加载.
- 每 10 秒刷新一次, 页面隐藏时暂停.

布局:

```
+---------------------------------------------------+
| 归档           [新建归档] [包含已删除] [房间 v]     |
+---------------------------------------------------+
| 名称 | 起止时间 | 样本数 | 创建时间 | 下载 | 删除    |
+---------------------------------------------------+
```

交互:

- 新建归档对话框:
  - 起止时间.
  - 可选名称.
  - 提示: 归档会从当前记录中移除这些样本, 操作不可撤销.
  - 确认按钮文案 "归档并移除".
- 下载: 同源链接, 文件名 `<name>.csv`.
- 删除: 二次确认, 提示是软删除, 可由管理员清理.
- 空状态: "还没有归档", 主按钮 "新建归档".
- 错误: 显示 problem `code`, 对 `archive_exists`, `archive_empty`, `storage_error` 给出不同建议.

### 6.4 设置 `/settings`

分组与字段:

1. 服务端连接
   - `base_url`: URL 输入, 必须 http/https, 不允许 query 与 fragment.
   - `token`: 密码输入, 留空表示不修改, 有 "清除 token" 按钮.
   - 测试连接: 保存后调用 `/api/status`, 显示结果.
2. 登录
   - 当前会话状态与更新时间.
   - 手动表单: `JSESSIONID`, `cookie`, `X-CSRF-TOKEN`, 三个密码输入.
   - 提交调用 `PUT /api/session`.
   - 说明推荐 `dormwatt client login`.
   - 安全提示: 值只发送到本地守护进程.
3. 房间
   - 当前房间: 名称, 编号.
   - 级联选择: 地区 -> 建筑 -> 楼层 -> 房间.
   - "设为活动房间" 调用 `PUT /api/rooms/{id}/active`.
   - "清除房间" 调用 `DELETE /api/rooms/active`, 二次确认.
4. 显示与通知
   - 时区: IANA 名称选择或输入.
   - 刷新间隔: 3, 5, 10, 30 秒.
   - 低电量阈值: 数字, 单位度.
   - 主题: 跟随系统 / 浅色 / 深色.
   - 浏览器通知: 授权按钮, 低电量开关, 电量回升开关.
5. 关于
   - 客户端版本, 服务端版本.
   - 配置路径, 日志路径.
   - 托盘状态.
   - 退出守护进程按钮, 二次确认.

表单规则:

- 保存使用 `PUT /api/settings`, 只提交改动字段.
- 保存中禁用按钮.
- 保存成功 toast, token 输入框清空.
- 修改 `local.bind` 返回 `restart_required`, 显示重启提示.
- 时区校验使用 `Intl.DateTimeFormat` 尝试构造.
- 阈值必须 >= 0 且 <= 100000.

### 6.5 登录帮助

- 独立路由 `/login-help`, 或设置页锚点 `#login`.
- 内容:
  1. 在终端执行 `dormwatt client login`.
  2. 在打开的浏览器中完成学校 SSO.
  3. 返回页面后点击 "我已登录".
  4. 无法使用浏览器时, 手动复制三个值.
- 不嵌入 ECNU 页面, 不使用 iframe.
- 提供复制命令按钮.

## 7. 状态与数据加载

### 7.1 四态

每个异步区域:

- `loading`: 骨架屏, 不显示空状态.
- `success`: 正常内容.
- `empty`: 图标, 一句解释, 一个行动按钮.
- `error`: 错误标题, `code`, 可读 detail, 重试按钮.

### 7.2 轮询

- 全局状态每 5 秒, 页面隐藏时暂停.
- 记录页不自动轮询, 用户操作或首次进入时加载.
- 归档页每 10 秒, 页面隐藏时暂停.
- 网络恢复或页面重新可见时立即刷新一次.
- 多个请求使用 `AbortController` 取消旧请求, 防止竞态覆盖.

### 7.3 错误映射

| code | 页面提示 | 建议动作 |
|------|----------|----------|
| `unauthorized` | 服务端 token 无效 | 到设置页更新 token |
| `forbidden` | token 权限不足 | 更换带 write scope 的 token |
| `room_not_configured` | 未选择房间 | 打开房间选择 |
| `ecnu_not_logged_in` | ECNU 登录失效 | 打开登录帮助 |
| `ecnu_upstream_error` | 学校接口异常 | 稍后重试, 查看服务端日志 |
| `archive_empty` | 该范围没有样本 | 调整时间范围 |
| `archive_exists` | 归档名称已存在 | 换一个名称 |
| `records_too_many` | 记录太多 | 收窄时间范围或导出 CSV |
| `upstream_unreachable` | 服务端不可达 | 检查地址, 网络与代理 |
| `rate_limited` | 请求过于频繁 | 等待后重试 |

## 8. 图表规格

- 库: ECharts, 按需引入 line, bar, dataZoom, tooltip, grid, legend.
- 图表容器必须设置固定高度, 避免布局抖动.
- 数据点超过 2000 时启用 `sampling: 'lttb'`.
- X 轴时间按 `ui.timezone` 格式化, 跨天时显示日期.
- Y 轴单位: 度.
- 剩余电量折线使用强调色.
- 用量柱状使用警告色, 与折线区分.
- Tooltip 显示时间, 电量, 与上一点差值.
- 电量回升点使用圆点标记, 并在 tooltip 提示 "充值或换表".
- 空数据不绘制坐标轴, 显示空状态.
- 图表销毁时调用 `dispose`, 防止内存泄漏.
- 主题切换时重新设置 option, 不重建实例.

## 9. 通知

- 只在用户点击 "开启通知" 时请求权限.
- 低电量通知:
  - 条件: 当前电量低于阈值, 且上一次状态不低于阈值.
  - 节流: 30 分钟内最多一次.
- 电量回升通知:
  - 条件: 当前电量比上一次高, 且开启开关.
  - 节流: 30 分钟.
- 多标签页:
  - `localStorage` 记录 `dormwatt.notify.last` 与类型.
  - 发送前检查窗口.
- 页面隐藏时不主动轮询, 恢复可见时补一次判断.
- 系统通知由本地守护进程发送, 与本页面是否打开无关. 设置页的 "系统通知" 开关对应 `client.toml` 的 `local.notify`; 保存后立即生效.
- 通知失败不阻塞页面, 只在控制台与 toast 提示.

## 10. 响应式与可访问性

- 断点: 640, 768, 1024, 1280.
- 1024 以下侧边栏折叠为图标.
- 768 以下使用底部导航.
- 表格在窄屏改为卡片, 或允许横向滚动并固定首列.
- 所有交互元素可键盘访问, 焦点可见.
- 图标按钮必须有 `aria-label`.
- 状态变化使用 `aria-live="polite"` 通知屏幕阅读器.
- 颜色对比度至少 4.5:1.
- 动画遵循 `prefers-reduced-motion`.
- 图表提供表格替代视图.

## 11. 安全与隐私

- 服务端 token 只存在于设置页输入框与本地守护进程, 不进入 URL 与 `localStorage`.
- 不在页面显示 cookie, CSRF 值.
- 不引入外部字体, 脚本, 图片与统计.
- 所有请求同源, 不配置 CORS.
- 写请求统一带 `X-Dormwatt-Client: 1` 与 JSON Content-Type.
- 错误 detail 以文本渲染, 不使用 HTML.
- 下载使用同源链接, 不打开新窗口执行脚本.
- 退出守护进程需要二次确认.

## 12. 性能预算

| 指标 | 目标 |
|------|------|
| 首屏可交互 | 1.5 秒内, 本地环境 |
| 首屏 JS gzip | 300 KiB 以内 |
| 图表 chunk | 按需加载, 不超过 300 KiB gzip |
| 状态轮询响应 | 100ms 内, 本地缓存命中 |
| 5000 条记录渲染 | 表格分页, 不一次性渲染 |
| 图表 10 万点 | 采样后不超过 2000 点 |

- 路由级代码分割.
- ECharts 只在记录页与仪表盘图表出现时加载.
- 记录数据请求使用 `AbortController`.
- 不缓存归档 CSV.
