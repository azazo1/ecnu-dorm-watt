# DormWatt v0.1.0

Date: 2026-10-22

首个公开版本. 包含 Go 服务端, 客户端 CLI, 本地 Web GUI 与系统托盘, 以及跨平台发布归档.

## Highlights

- 服务端提供 ECNU 电量与目录查询, SQLite 存储, 归档事务和 Bearer Token 鉴权.
- 客户端支持 CLI 直连, 本地 Web GUI, 三平台托盘, 浏览器登录与系统通知.
- 提供 6 个平台与架构的发布归档, 每个归档同时包含 `dormwatt` 与 `dormwatt-server`.

## Features

- 服务端: ECNU 上游查询, SQLite 存储, 记录与归档, 多房间, token 管理, 子路径反向代理部署.
- 服务端: 路由固定为 `/v1/...`, 外部 `/dormwatt/api` 前缀由反向代理剥离.
- 客户端: 本地 Web GUI, 系统托盘, 浏览器登录与手动登录, 系统通知, `--no-open`, Ctrl+C 优雅退出.
- 发布: 6 个平台与架构归档, 每个归档包含桌面版与服务端静态版, 附带 `SHA256SUMS`.
